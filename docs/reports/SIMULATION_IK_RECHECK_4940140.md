## 仍失败的四例

| 用例 | 上版实测 | 本版实测 | 验收线 |
| --- | ---: | ---: | --- |
| H01 左腕边界姿态 | 越限 0.000324 rad | 越限 **0.000025 rad**，尾段位置误差 0.033 mm | 全程越限 ≤0.000010 rad |
| M04 右臂静态位姿 | 14.3611 mm | **14.3611 mm / 0.03471 rad** | ≤0.01 mm / 0.0001 rad |
| M05 右臂静态位姿 | 7.3624 mm | **7.3624 mm / 0.02801 rad** | ≤0.01 mm / 0.0001 rad |
| E01 向上画圆 | 峰值 451.493 mm | 峰值 **5.419 mm**，全程无接触 | 运动峰值 <1 mm，接触数为 0 |

**E01 的改善主要来自评测器的差分 IK 阻尼。** 将本版评测器用于旧版代码与模型，同样得到 5.419 mm。在本版只把评测阻尼从 0.045 调回旧值 0.00001，误差回到 451.673 mm。使用库的默认参数、仅指定 TCP 站点，峰值为 7.021 mm。本版评测的峰值发生在 1.90 s 的右臂，此时对参考关节角做正运动学，已与目标相差 5.242 mm。4 s 保持段最后三个采样的位置误差均低于 0.018 mm。[评测参数](../../tests/eval_regression_25.py#L61) · [库默认参数](../../src/ik_solver.py#L53)

**右臂坐标差异仍影响三个用例。** E01 冻结首帧的右 TCP 与相同关节角在本版模型的正运动学相差 43.022 mm / 0.05929 rad。仅在临时副本中，根据这对位姿估计刚体变换并对齐右臂目标，E01 降到 0.875 mm，M05 低于 0.0001 mm。M04 对齐后为 0.0350 mm，进一步将求解容差设为该用例的验收线后，达到 0.00537 mm / 0.0000117 rad。工程报告中对齐后的 0.856 mm 来自上版，本版同法复现为 0.875 mm。严格回归的 21/25 使用冻结文件中的原始目标。[工程报告](SIMULATION_IK_GRASP_REPORT.md#L60) · [全局 IK 求解容差](../../src/ik_solver.py#L351)

**H01 对关节边界余量敏感。** 在临时对照中保留原始世界坐标目标与轨迹时长，只给左腕 J5 末段关节目标留出 0.001 rad 的上限余量。实测最大越限降至 0.000005 rad，尾段误差为 0.210 mm / 0.00100 rad，通过原判据。发布版的 H01 结果仍取表中数值。[模型关节限位](../../src/build_mjcf.py#L325) · [动态判据](../../tests/eval_regression_25.py#L286)

## 如何解读 21/25

- 默认控制器对 J1–J4、J5–J6 分别限幅 20、5 N·m。只把控制器限幅改成数据集的额定 9、3 N·m，其余配置相同，通过数降到 **20/25**。E01 峰值为 **34.125 mm**，E04 从 **0.998 mm** 升到 **3.980 mm**，两例全程无接触。仓库 E 组先用 IK 对齐首帧，再以 10 ms 间隔统计运动位置峰值，以每个物理步检查接触。实机精度和制动距离仍待实机测试。[额定力矩](../../ik_regression_25/manifest.json#L243) · [控制器限幅](../../src/controller.py#L55) · [轨迹评测](../../tests/eval_regression_25.py#L191)
- 工程报告把 C 组描述为接触刚体对完全匹配。实际判据要求正例的标记对全部出现，并允许出现额外接触。C04、C05 各标记 1 对，当前模型分别检出 16、7 对不同刚体，均命中标记。该结果验证了这两对已知碰撞，额外接触的真实性需要原始网格复核。[工程报告表述](SIMULATION_IK_GRASP_REPORT.md#L53) · [碰撞判据](../../tests/eval_regression_25.py#L111)

## 复跑

在当前提交的干净副本中，使用 Python 3.10.12、MuJoCo 3.17.0、Mink 1.3.0、DAQP 0.11.2，物理步长 2 ms。冻结数据的 SHA-256 校验通过。由 URDF 重建的三个 MJCF 与碰撞网格、重新生成的 25 例及抓放 JSON，均与本版提交逐字节一致。以下测试中严格回归按预期返回 1，其余返回 0。抓放与回归脚本会写入运行副本的 `docs/` 目录。

```bash
sim_python=/home/lakeside/.venvs/mujoco/bin/python
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
"$sim_python" tests/audit_sim_ik.py
"$sim_python" tests/verify_sim_ik.py
"$sim_python" -m src.sim_runner
"$sim_python" tests/test_grasp_pick_place.py
"$sim_python" tests/probe_grasp_execution.py
"$sim_python" tests/eval_regression_25.py --strict
```
